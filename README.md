# My Personal Site
My personal site and portfolio, dark space theme custom `css`

[**Live website**](https://alomnsh.github.io/My-Personal-Site/#)

## Included Projects
*   **ARC Plane:** Custom foam board RC plane using Flite Test electronics. 11+ hours logged
*   **LVR 21-ZR Edition:** Autonomous robot using VEX V5 hardware with object avoidance, finding its way and collection.
*   **The Ares Horizon:** A NASA Flight Director simulation game focused on Mars exploration includes a story mode with a built in minigame
*   **Frictionless Notes:** A free, private tool that converts recorded lectures into note keeping privacy its top priority.
